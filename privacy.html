개인정보처리방침 — Remember Contact Sync

시행일: 2026-10-02

1. 이용 대상

이 앱은 소유자 본인 1인이 본인 Google 계정에 대해서만 사용하는 개인용 도구입니다.

2. 접근하는 데이터

Google People API의 contacts.readonly 범위로 본인 주소록의 이름·회사·직함·이메일·전화·주소를 읽습니다.
주소록을 수정·삭제하지 않습니다.

3. 사용 목적과 보관

가져온 연락처는 소유자 PC의 로컬 SQLite 파일에만 저장하며, 본인의 명함 검색·관리에만 사용합니다.
외부 서버 전송, 제3자 제공, 광고·분석 목적 사용은 하지 않습니다.

4. 삭제

로컬 파일을 지우거나 Google 계정 설정의 "타사 앱 액세스"에서 권한을 해제하면 즉시 중단·삭제됩니다.

5. Google API 사용자 데이터 정책

이 앱의 Google API 데이터 사용은 제한적 사용(Limited Use) 요건을 포함한 Google API Services User Data Policy를 따릅니다.

English summary

Single-user personal tool. Reads the owner's own Google Contacts with the read-only scope and stores them only in a local database on the owner's PC. No transfer to third parties, no advertising or analytics. Use of data received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
